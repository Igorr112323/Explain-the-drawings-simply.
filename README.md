# IkGuide — 2D-чертёж → готовый PDF-инструкция

Однозадачный продукт: **перетащили файл — скачали `.pdf` с понятной инструкцией в стиле IKEA.**
Никаких мобильных приложений, QR-кодов, ролей, аккаунтов и облака: распознавание, сборка шагов,
схемы и сам PDF считаются на этом же компьютере.

```
Кронштейн.pdf  ──▶  [ IkGuide ]  ──▶  Кронштейн_КС-04_инструкция.pdf
                                       титул · схемы шагов · «что понадобится»
                                       шпаргалка ГОСТ · «ОСТОРОЖНО» · чек-лист
```

Что внутри PDF: обложка с общей схемой, «Что понадобится (детали и крепёж)», «Возьми инструмент»,
«Шпаргалка по значкам и допускам» (`Ø20 H7 → от 20,000 до 20,021 мм, нужна развёртка`), шаги по два
на A4 с крупными номерами и векторными схемами в трёх цветах, красные рамки «ОСТОРОЖНО»,
«Контрольный замер» и последняя страница-чек-лист с `[ ]`.

---

## Как это выглядит для человека

1. **Экран загрузки.** Крупная зона «Перетащите 2D-чертёж или PDF сюда», кнопка выбора файла и два
   примера, которые открываются мгновенно и без сети: «Кронштейн КС-04» и «Редуктор РД-12».
2. **Экран предпросмотра.** На белом холсте с точечной сеткой — живые листы A4 «как в файле»,
   строка «Стр. 1 из 3» под каждым листом и мини-пилюля `− 100% +` в углу: колесо и пинч дают
   40–250 %, `Ctrl/Cmd +`, `−`, `0` — как в браузере, клик по проценту возвращает 100 %.
3. **Нечёткий размер.** Если распознавание колебалось (`12` или `18`?), появляется жёлтая плашка:
   один клик по варианту — и значение исправляется в схеме, тексте шагов, критериях приёмки и чек-листе.
4. **Файл.** Кнопка сразу отдаёт бинарный `.pdf` (`Кронштейн_КС-04_инструкция.pdf`). Диалог печати не
   открывается никогда: в браузере это скачивание, в `.exe` — нативное «Сохранить как…».

## Быстрый старт

```bash
npm install
npm run build:packages      # schema + gost-translator + builder (+ pdf-exporter) в dist
npm run dev                 # http://localhost:5173 — UI; примеры работают и без бэкенда
```

Для загрузки своих файлов нужен локальный бэкенд (Python, ничего не уходит в интернет):

```bash
npm run install:vision          # один раз: .venv сервиса распознавания
npm run dev:all                                 # сервисы + UI на одном экране
```

Без бэкенда UI не падает: он объясняет, что запустить (`npm run dev:all`), и предлагает открыть пример.

## Что поддерживается на входе

| Вход | Путь | Что получается |
| --- | --- | --- |
| JPG, JPEG, PNG, WEBP, PDF (до 8 листов) | `POST /v1/recognize` → `buildGuideFromVision` | шаги по обозначениям, шаги комплектности по таблице позиций, ориентиры по видам, инструмент, контрольные замеры, жёлтые вопросы, зона кропа на каждый шаг |

## Структура

```
packages/
  ikguide-schema/      Zod-схема IkGuideDocument: метаданные, детали, инструмент, шаги, аннотации
  gost-translator/     детерминированный перевод обозначений ГОСТ/ЕСКД (без LLM)
  ikguide-builder/     распознанное → документ инструкции (шаги, инструмент, чек-лист)
  pdf-exporter/        план листов A4 + рендер настоящего PDF (jsPDF + svg2pdf, вшитый шрифт)
apps/
  studio-web/          единственный UI: загрузка → предпросмотр → PDF
  desktop-tauri/       Tauri v2: то же окно + нативное «Сохранить как…»
services/
  vision-api/          OpenCV/PyMuPDF/RapidOCR: лист, штамп, обозначения с координатами
  vision-api/tables.py  таблица позиций и подписи видов → данные для шагов комплектности
scripts/               dev-all, локальный бэкенд, шрифты PDF, иконки, проверки конфигов
```

## PDF: почему он настоящий

* Рендер целиком на клиенте: **jsPDF + svg2pdf.js**, без сервера и без `window.print()`.
* Кириллица — **вшитые подмножества DejaVu Sans** (regular + bold, base64 в бандле): ни одного запроса
  в сеть, ни одного квадратика вместо буквы. `Ø ± ° × №` на месте.
* Графика — **100 % вектор**: SVG шагов встраиваются как векторные команды PDF, без растеризации.
* Размер и переносы строк считаются по реальным метрикам шрифта (`packages/pdf-exporter/src/text.ts`),
  поэтому предпросмотр в браузере и файл совпадают до строки.
* Готовые файлы: ~50–120 КБ на инструкцию из 5–7 листов A4.
* Один файл: `IKGuide-Studio-Setup.exe` — установщик со встроенным движком. Скачал, запустил,
  проверил: ничего доустанавливать не нужно.
* Скорость: первый экран не тянет рендер — jsPDF подгружается только по нажатию «Скачать PDF-инструкцию».
* Интерфейс: белый холст с точечной сеткой и пятью парящими белыми капсулами — как в Apple Freeform.
  Документ лежит прямо на холсте листами A4; масштаб 40–250 % — единственное добавление к холсту,
  и оно спрятано в мини-пилюлю `− 100% +`.
* Установщик: **NSIS** с собственным белым шаблоном (`src-tauri/nsis/installer.nsi`) и картинками
  мастера, четыре шага — приветствие → папка → установка → «Готово», без выбора языка (только русский).
* Распознавание: мелкие листы (< 1400 px) увеличиваются в 2–3 раза, из листа читаются таблица позиций
  и подписи видов — таблица становится шагами комплектности, виды — шагами-ориентирами.

## Приватность

Движок слушает только `127.0.0.1:8000`, браузер ходит в него через прокси Vite, в `.exe` — напрямую на
loopback. Ни одна картинка или строка не покидает компьютер: нет телеметрии, нет загрузки на сервер,
нет внешних шрифтов. Sidecar поднимается вместе с окном и гасится вместе с ним (`taskkill /T`).

## Ограничения, о которых честно

* `.exe` собирается только на Windows или в GitHub Actions: в Linux-песочнице нет Rust. Конфигурация
  при этом проверяется (`npm run check:native`, 145 проверок), а CI собирает установщик и движок.
* Движок распознавания (`ikguide-vision.exe`, PyInstaller) — отдельная джоба: если он не собрался,
  установщик всё равно выйдет, а приложение честно скажет, что фото и сканы пока не читаются
  (векторные PDF работают всегда).
* Только 2D. STEP/STL/OBJ/GLB не принимаются: продукт делает инструкции по чертежам.
* Точность распознавания — свойство скана: уверенность ниже 0.95 не скрывается, а превращается в
  жёлтый вопрос «12 или 18 мм?». Автоматика не выдумывает размеры.
* Электронного архива нет: результат — файл PDF. Листы и схемы остаются в памяти вкладки до
  перезагрузки.
