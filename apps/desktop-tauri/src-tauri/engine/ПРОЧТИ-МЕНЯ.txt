Локальный движок IKGuide.

Сюда CI кладёт ikguide-vision.exe и ikguide-cad.exe (PyInstaller), собранные в той же джобе
workflow «Build Windows .exe», перед сборкой установщика. В git лежит только этот файл-заглушка:
без него glob «engine/*» в tauri.conf.json не находит ни одного файла, и `tauri build` падает.

Приложение запускает движок само при старте, без окна консоли. Если файлов нет — студия работает
с уже запущенным сервером на 127.0.0.1:8000/8001 либо в режиме демо.
